> **Status: Current.** Reference for users. The rows of the tables are generated by
> `docs/scripts/controls-table.mjs` from the library sources and from the list of tester members
> in that script; `npm test` fails when the rows differ from its output or a tester is missing.

Each row names a type of the UI framework, the substitute class that replaces it, the kind of
substitution, the tester that finds it by name, the testing events the substitute raises, including
those it inherits from another substitute class, and the members the tester adds beyond `Target`
and `Handle`.
[Test a Windows Forms application](winforms.md) and [Test an Avalonia application](avalonia.md)
explain how to use them.

`CommonDialog`; `MessageBox` is substituted through its static `Show` overloads. Every other

Two testers address parts of a control rather than a control: `GridItemTester`, returned by
`PropertyGridTester.FindGridItem`, with `Value`, `Children` and `Edit()`; and `TreeNodeTester`,
returned by `TreeViewTester.FindNode` and its indexer, with `Target`, `TreeViewTester`, `Select()`,
`Click()`, `FindByTagType(Type)` and an indexer for child nodes.

### Testing events

`TestingWinformsEventKind` lists many kinds of event, but the substitutes raise these nine:
`Activated`, `CheckedChanged`, `Click`, `DoubleClick`, `ItemCheck`, `NodeMouseClick`,
`NodeMouseHover`, `SelectedItemChanged` and `Shown`. `Shown` is raised by `Form`, by every
common dialog from `RunDialog`, and by `MessageBox.Show`.

`ValueChanged`.
